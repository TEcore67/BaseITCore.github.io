Getting started

This quickstart helps you explore the static UI locally and on GitHub Pages.

  1. Open index.html for marketing context and navigation.
  2. Visit dashboard/index.html to interact with mock KPIs, users, and roles.
  3. Use the theme toggle to verify accessibility contrast.
  4. Navigate docs with the sidebar search and keyboard shortcut /.
  5. Update copy with Drive-sourced terminology when available.
Run locally: python -m http.server in the project root keeps relative paths working for GitHub Pages.
