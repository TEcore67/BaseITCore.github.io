API-style reference

Use these endpoint-inspired examples to map the static UI to future backend contracts. Replace payloads with Drive-sourced definitions.

GET /policies

Retrieve policy baselines and drift signals.

{
  "items": [
    { "id": "baseline-eu", "status": "healthy", "exceptions": 2 },
    { "id": "baseline-us", "status": "watch", "exceptions": 5 }
  ]
}

POST /exceptions

Request a temporary policy exception.

{
  "policyId": "baseline-eu",
  "reason": "Maintenance window",
  "expiresAt": "2024-12-31T00:00:00Z"
}

GET /analytics

Surface governance KPIs (drift, approvals, remediation time).

{
  "kpis": [
    { "name": "drift_detected", "value": 3 },
    { "name": "exceptions_open", "value": 12 },
    { "name": "automation_coverage", "value": 0.87 }
  ]
}
